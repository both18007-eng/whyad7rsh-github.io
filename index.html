Unlocking the bootloader

Required before flashing any custom recovery or ROM. Xiaomi requires an official unlock through Mi Unlock Tool, tied to your Mi account.

  1. Add your Mi account to the phoneSettings → Additional settings → Developer options → sign in with a Mi account, and turn on OEM unlocking + USB debugging.
  2. Apply for permissionOn the Mi Unlock status page, request unlock permission. Xiaomi usually adds a waiting period, from a few hours to several days.
  3. Install Mi Unlock ToolDownload it on a PC from Xiaomi's official unlock site and sign in with the same Mi account.
  4. Boot to fastboot modePower off, then hold Volume Down + Power until the fastboot logo appears. Connect via USB.
  5. UnlockIn Mi Unlock Tool, click Unlock and confirm on the phone screen. The device will reboot and reset itself.
Terminal / Command Prompt$adb reboot bootloader
$fastboot devices
$fastboot flashing unlock

Unlocking wipes all data on the phone and voids some warranty protections. Back up everything first.

Flashing a custom ROM

Once unlocked, a custom recovery lets you flash any ROM built for raphael.

  1. Flash a custom recoveryBoot the recovery image (e.g. TWRP or OrangeFox) with fastboot boot recovery.img, then flash it permanently from inside recovery if you plan to keep using it.
  2. Copy the ROM to the phonePush the ROM zip via adb push rom.zip /sdcard/ or copy it over MTP while in recovery.
  3. Wipe before flashingIn recovery, wipe Dalvik/ART cache, cache, and data if you're switching ROM families. Keep internal storage untouched.
  4. Flash ROM, then GApps if neededInstall the ROM zip first, then a GApps package matching the Android version, in the same session.
  5. RebootFirst boot after a fresh ROM can take several minutes — let it sit.
Terminal / Command Prompt$fastboot boot recovery.img
$fastboot flash recovery recovery.img
$adb push rom.zip /sdcard/
$adb sideload rom.zip
$fastboot reboot

Relocking the bootloader

Useful before selling the phone or returning to a fully stock, locked state.

  1. Flash the latest official stock ROM firstRelocking on a custom ROM/recovery can hard-brick the device. Always go back to stock fastboot ROM before relocking.
  2. Boot into fastboot modeVolume Down + Power, then connect to PC.
  3. Run the lock commandfastboot oem lock — the phone will reset again.
Terminal / Command Prompt$adb reboot bootloader
$fastboot oem lock

Never relock while a custom recovery or ROM is still on the device — this is the most common cause of a hard brick.

Flashing back to stock ROM

Uses Xiaomi's official Mi Flash Tool with a fastboot ROM package.

  1. Download the fastboot ROMGet the matching fastboot package for raphael from Xiaomi's official firmware site.
  2. Install Mi Flash ToolOfficial Xiaomi PC tool for flashing fastboot ROMs.
  3. Extract and select the ROM folderPoint Mi Flash Tool to the extracted fastboot ROM directory.
  4. Boot to fastboot, connect, flashChoose "clean all" to fully wipe, or "save user data" to keep files, then click Flash.
Terminal / Command Prompt$adb reboot bootloader
$fastboot getvar all
$fastboot reboot
